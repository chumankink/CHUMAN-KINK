Configuration administrateur requise

Le serveur reste verrouillé tant que les deux secrets suivants ne sont pas définis dans les Secrets de Replit :

  • CK_ADMIN_PASSWORD : mot de passe administrateur long et unique.
  • CK_SECRET_KEY : clé aléatoire longue utilisée pour signer les sessions.

Après les avoir ajoutés, redémarre l'application. Ne partage jamais ces valeurs dans une conversation ou dans le code.
